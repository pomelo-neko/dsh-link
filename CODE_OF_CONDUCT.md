# Code of Conduct

## Our pledge

We want dsh-link to be a project where anyone can participate without harassment, regardless of
experience level, language, nationality, gender identity, disability, appearance, or beliefs.

## Expected behaviour

- Be kind and assume good faith. Explain the *why* behind a review comment.
- Keep feedback about the code, not the person.
- Respect that maintainers and contributors work across different time zones and languages; write
  plainly and avoid idioms that do not translate.
- Do not publish other people's private information — including hostnames, file paths, tokens,
  message logs or DSH transcripts — in issues, PRs or discussions. When a bug report needs real
  data, redact it first.

## Unacceptable behaviour

Harassment, insults, discriminatory jokes, sexualised attention, deliberate intimidation,
doxxing, sustained disruption of discussions, and publishing someone's private data.

## Scope

This applies in all project spaces (issues, pull requests, discussions, commit messages) and when
an individual is representing the project in public.

## Reporting and enforcement

Report a problem privately through the repository's **Security → Report a vulnerability** form or
by contacting a maintainer directly (see `SECURITY.md`). Maintainers will review every report,
keep it confidential, and respond within a reasonable time. Consequences range from a private
warning to a permanent ban from the project, at the maintainers' discretion.

version 2.1.
